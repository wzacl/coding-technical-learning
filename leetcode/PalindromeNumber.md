
# Hint

Given a string `s`, return _the longest_ _palindromic_ _substring_ in `s`.

**Example 1:**

`Input: s = "babad"`
`Output: "bab"`
`Explanation: "aba" is also a valid answer.`

**Example 2:**

`Input: s = "cbbd"`
`Output: "bb"`

**Constraints:**

- `1 <= s.length <= 1000`
- `s` consist of only digits and English letters.


    

#  方法一：轉成字串，比較左右對稱位置

核心想法：**所有對稱位置都相同，才是回文；任何一組不同，就能立即判定不是回文。**

處理流程：

1. 用 `str(x)` 轉成字串。
    
2. 用 `len()` 取得長度 `k`。
    
3. 左側索引使用 `i`，右側索引使用 `k - 1 - i`。
    
4. 只比較 `k // 2` 組。
    
5. 發現不同就回傳 `False`；迴圈結束後回傳 `True`。
    

以 `"1221"` 為例：

|`i`|左側索引|右側索引|比較內容|
|---|--:|--:|---|
|0|0|3|`"1"` 與 `"1"`|
|1|1|2|`"2"` 與 `"2"`|

只比較一半的原因：

- 偶數長度：每個字元都有對稱位置。
    
- 奇數長度：中間字元與自己相同，不需比較。
    
- 單一字元：`k // 2` 為 `0`，不用比較，直接回傳 `True`。
    

# 方法二：用整數運算反轉完整數字

核心想法：**依序取出原數字的個位數，組成反轉後的整數，最後與原數字比較。**

|變數|角色|
|---|---|
|`x`|原始數字，保留作為比較依據|
|`num`|尚未處理的部分|
|`rem`|本輪取出的個位數|
|`op`|已取出位數組成的反轉結果|

每輪包含三個操作：

```python
rem = num % 10       # 取得個位數
op = op * 10 + rem    # 將新位數接到反轉結果後面
num //= 10           # 移除已處理的個位數
```

`op * 10` 先把原本的數字向左移一位，再以 `+ rem` 補上新個位數。例如：

```python
op = 3
rem = 2
op = op * 10 + rem  # 32
```

以 `x = 123` 手動追蹤：

|階段|本輪取出的 `rem`|更新後的 `num`|更新後的 `op`|
|---|--:|--:|--:|
|初始|—|123|0|
|第一輪|3|12|3|
|第二輪|2|1|32|
|第三輪|1|0|321|

第二輪結束時，`num = 1`，代表仍有一位尚未處理。直到 `num = 0`，才完成完整反轉。

最後的判斷：

```python
return op == x
```

`==` 本身會產生 `True` 或 `False`，不需要另外包一層 `if`。

#  資料結構、語法與迴圈選擇

題目指定的輸入是 **`int` 整數**；字串是第一種方法自行建立的輔助資料表示。

|語法／操作|意義|
|---|---|
|`str(x)`|將整數轉成字串|
|`len(read)`|取得字串長度|
|`read[i]`|取得索引 `i` 的字元，索引從 `0` 開始|
|`range(k // 2)`|產生需要比較的左側索引|
|`num % 10`|對非負整數取得個位數|
|`num // 10`|對非負整數移除個位數|
|`num //= 10`|等同 `num = num // 10`，會更新變數|
|`return`|立即結束整個函式，回傳結果|

迴圈選擇依據：

- **字串版用 `for`：** 已知道比較組數，可以走訪固定索引範圍。
    
- **整數版用 `while`：** 依「是否還有位數未處理」決定繼續，條件是 `num > 0`。
    
- 這是依資料存取方式與停止條件選擇，不代表整數問題只能用 `while`。
    

另外，`num = x` 之後更新 `num`，不會改變 `x`。Python 整數不可變，更新會讓 `num` 指向新的整數。

# 本次實際犯過的錯誤

本次程式中發現的是**邏輯錯誤**，沒有發現一般 Python 語法錯誤或執行時錯誤。

## 錯誤一：右側索引固定在最後一位

原寫法：

```python
if read[i] != read[k-1]:
```

修正：

```python
if read[i] != read[k-1-i]:
```

- **原因：** `k - 1` 永遠指向最後一個字元，沒有隨左側索引移動。
    
- **正確關係：** 左側每往右一格，右側就要往左一格。
    
- **避免方法：** 列出前兩輪索引，確認是 `(0, k-1)`、`(1, k-2)`。
    

## 錯誤二：第一組相同就回傳 `True`

原寫法：

```python
if read[i] != read[k-1]:
    return False
else:
    return True
```

- **原因：** `return True` 放在迴圈內，第一組相同就結束整個函式。
    
- **反例：** `1231` 的外側相同，但內側 `2` 與 `3` 不同。
    
- **修正：** 移除 `else`，將 `return True` 放到迴圈後，與 `for` 對齊。
    
- **延伸影響：** 原寫法遇到單一數字時，迴圈不執行，也沒有其他 `return`，函式會隱含回傳 `None`。
    

要記住的判斷原則：

> 找到一個反例，就能否定「全部成立」；確認「全部成立」，則需要完成所有必要檢查。
