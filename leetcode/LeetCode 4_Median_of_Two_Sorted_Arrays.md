# Problem description：

Given two sorted arrays `nums1` and `nums2` of size `m` and `n` respectively, return **the median** of the two sorted arrays.

The overall run time complexity should be `O(log (m+n))`.
**Example 1:**

`Input: nums1 = [1,3], nums2 = [2]`
`Output: 2.00000`
`Explanation: merged array = [1,2,3] and median is 2.`

**Example 2:**

`Input: nums1 = [1,2], nums2 = [3,4]`
`Output: 2.50000`
`Explanation: merged array = [1,2,3,4] and median is (2 + 3) / 2 = 2.5.`

**Constraints:**

- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-106 <= nums1[i], nums2[i] <= 106`

# Python Solution：

```python
class Solution(object):

    def findMedianSortedArrays(self, nums1, nums2):

        """

        :type nums1: List[int]

        :type nums2: List[int]

        :rtype: float

        """

        if len(nums1)>len(nums2):

            nums1,nums2=nums2,nums1

  

        low,high=0,len(nums1)

        length = (len(nums1)+len(nums2)+1)//2

  

        while low <= high :

            i = (low + high) // 2

            j = length - i

            left1 = nums1[i - 1] if i > 0 else float("-inf")

            right1 = nums1[i] if i<len(nums1) else float("inf")

            left2 = nums2[j - 1] if j > 0 else float("-inf")

            right2 = nums2[j] if j < len(nums2) else float("inf")

            if (left1 > right2):

                high = i-1

            elif(right1<left2):

                low = i + 1

            else:

                break

        total = len(nums1)+len(nums2)

        left_max = max(left1,left2)

        right_min = min(right1,right2)

        if total % 2 == 1:

            return left_max

        else:

            return (left_max+right_min)/2
```

# **1. 題目資訊與核心概念**

- **題號／名稱：** 4. Median of Two Sorted Arrays。
    
- **難度：** Hard。
    
- **使用語言** ：Python，建議選擇 Python 3。
    
- **輸入：** 兩個各自已排序的陣列，可以有重複值、負數，其中一個可以為空。
    
- **輸出：** 全部元素一起排序後的中位數。
    
- **限制：** 總長度至少為 `1`，時間複雜度要求 `O(log(m+n))`。
    

題目不要求真的建立合併陣列。只要找到正確切分，使：

- 左半部與右半部數量相同；總長度為奇數時，左半部多一個。
    
- 左半部所有元素，都不大於右半部所有元素。
    

就能透過交界值取得中位數：

|總長度|中位數|
|---|---|
|奇數|左半部最大值|
|偶數|左半部最大值與右半部最小值的平均|

# **2. 資料結構與變數角色**

題目指定的資料使用 Python `list` 表示。已排序的性質讓我們能直接用索引取得切點兩側的最大、最小值，無須切片或逐一搜尋。

本題只需要額外的數值變數，不需要建立輔助陣列。

| 變數               | 角色                                |
| ---------------- | --------------------------------- |
| `nums1`          | 交換後的較短陣列，二分搜尋的對象                  |
| `nums2`          | 另一個陣列                             |
| `low`、`high`     | 切點的候選範圍，包含兩端                      |
| `i`              | `nums1` 分到左半部的元素數量                |
| `j`              | `nums2` 分到左半部的元素數量                |
| `length`         | 整體左半部需要的元素數量，改名 `left_count` 會更清楚 |
| `left1`、`right1` | `nums1` 切點左側最大值、右側最小值             |
| `left2`、`right2` | `nums2` 切點左側最大值、右側最小值             |
| `total`          | 兩個陣列的總長度                          |

**切點表示數量，不是某個元素本身。**例如 `i = 2`，代表左側拿了兩個元素，左側最後一個索引是 `1`，右側第一個索引是 `2`。

# **3. 解題流程與重要判斷**

1. 將較短的陣列放在 `nums1`，縮小搜尋範圍，也讓推算出的 `j` 保持合法。
    
2. 計算左半部目標數量：
    
    ```python
    length = (len(nums1) + len(nums2) + 1) // 2
    ```
    
3. 在 `0` 到 `len(nums1)` 之間搜尋切點。包含兩端，因為可以一個元素都不取，也可以全部取。
    
4. 每輪重新計算：
    
    ```python
    i = (low + high) // 2
    j = length - i
    ```
    
5. 取得四個邊界值，檢查跨陣列的大小關係：
    
    |判斷|意義|更新|
    |---|---|---|
    |`left1 > right2`|`nums1` 左側放入太大的值|`high = i - 1`|
    |`left2 > right1`|`nums2` 左側放入太大的值|`low = i + 1`|
    |兩者都不成立|切分成功|結束搜尋|
    
6. 依總長度奇偶計算並回傳中位數。
    

你寫的 `right1 < left2` 與 `left2 > right1` 等價，沒有錯。

**為什麼可以二分搜尋？**當 `left1 > right2`，繼續增加 `i` 只會讓 `left1` 變大或不變，同時讓 `right2` 變小或不變，因此目前切點及更大的切點都能排除。另一個方向同理。

**為什麼使用 `while`？**本題以「候選範圍是否仍存在」作為繼續條件，每輪依比較結果更新範圍。`while low <= high` 能直接表達這個流程；不是所有陣列題目都必須用 `while`。

# **4. 空邊界與 Python 語法**

切點在陣列兩端時，某一側沒有元素：

|邊界|有元素的條件|有元素時讀取|空側替代值|
|---|---|---|---|
|`left1`|`i > 0`|`nums1[i - 1]`|負無限大|
|`right1`|`i < len(nums1)`|`nums1[i]`|正無限大|
|`left2`|`j > 0`|`nums2[j - 1]`|負無限大|
|`right2`|`j < len(nums2)`|`nums2[j]`|正無限大|

- 左側使用 `float("-inf")`，讓空側不影響最大值的選取。
    
- 右側使用 `float("inf")`，讓空側不影響最小值的選取。
    
- 無限大只存在於邊界變數中，不會插入原始陣列。
    

條件運算式範例：

```python
left1 = nums1[i - 1] if i > 0 else float("-inf")
```

Python 會先判斷條件，再只計算被選中的分支，因此能避免非法索引。

其他本次用到的語法：

|語法|意義|
|---|---|
|`a, b = b, a`|交換兩個變數所指向的資料|
|`//`|向下取整除法，用於數量、切點計算|
|`% 2`|取除以 2 的餘數，判斷奇偶|
|`break`|結束目前迴圈，繼續執行迴圈後面的程式|
|`return`|結束整個函式，回傳結果|
|`max(a, b)`／`min(a, b)`|取得較大／較小的值|

|總長度|中位數|

**2. 資料結構與變數角色**

題目指定的資料，在 Python 中以 `list` 表示。串列支援索引存取，而且題目保證已排序，因此可以直接讀取切點旁的元素，不需要切片後再搜尋最大、最小值。

本題額外使用的是固定數量的變數，沒有建立新的串列。

|變數|角色|
|---|---|
|`nums1`、`nums2`|兩個已排序串列；交換後讓 `nums1` 較短|
|`low`、`high`|`nums1` 切點的候選範圍，包含兩端|
|`i`|`nums1` 分到左半部的元素數量|
|`j`|`nums2` 分到左半部的元素數量|
|`length`|你的程式中代表左半部目標數量，可命名為 `left_count`|
|`left1`、`left2`|兩個陣列各自的左側最大值|
|`right1`、`right2`|兩個陣列各自的右側最小值|
|`total`|兩個陣列的總長度|

**切點是元素數量，不是左侧最後一個元素的索引。**

例如 `i = 2`，表示左側取前兩個元素：

- 左側最後一個：`nums1[i - 1]`
    
- 右側第一個：`nums1[i]`
    

**3. 解題流程與重要判斷**

1. 將較短陣列放在 `nums1`，讓搜尋範圍較小，也使對應的 `j` 保持合法。
    
2. 初始化切點範圍為 `0` 到 `len(nums1)`，因為可以取零個或全部元素。
    
3. 每輪選取範圍中間的 `i`，再由左半部目標數量算出 `j`。
    
4. 安全地取得四個邊界值。
    
5. 根據跨陣列比較，縮小範圍或結束搜尋。
    
6. 依總長度奇偶計算並回傳中位數。
    

|判斷|代表意義|動作|
|---|---|---|
|`left1 > right2`|`nums1` 左側取太多|`high = i - 1`|
|`left2 > right1`|`nums1` 左側取太少|`low = i + 1`|
|兩者都不成立|切分成功|`break`，接著計算答案|

你的 `right1 < left2` 與 `left2 > right1` **完全等價，不是錯誤**。

之所以能使用二分搜尋，是因為陣列已排序，失敗的比較能排除整段候選切點。例如 `left1 > right2` 時，增加 `i` 只會讓 `left1` 不減、`right2` 不增，因此目前及更大的切點都可以排除。

使用 `while low <= high`，是因為要持續處理尚未排除的候選範圍，迭代次數由比較結果決定。`low == high` 時仍有一個切點需要檢查，因此要用 `<=`。

你最後採用的**迴圈內 `break`、迴圈外計算答案**是可行的。`break` 離開迴圈，`return` 才結束整個函式。

**4. 空邊界的處理**

|情況|邊界值|
|---|---|
|某個陣列左側沒有元素|使用負無限大 `float("-inf")`|
|某個陣列右側沒有元素|使用正無限大 `float("inf")`|

理由是：

- 負無限大不會搶走真正元素的最大值。
    
- 正無限大不會搶走真正元素的最小值。
    
- 這些是比較用的替代值，沒有實際加入陣列。
    

關鍵片段：

```python
left1 = nums1[i - 1] if i > 0 else float("-inf")
```

條件運算式只會計算選中的那一側，因此必須**先確認元素存在，才讀取索引**。
