Given a string `s`, return _the longest_ _palindromic_ _substring_ in `s`.

**Example 1:**

**Input:** s = "babad"
**Output:** "bab"
**Explanation:** "aba" is also a valid answer.

**Example 2:**

**Input:** s = "cbbd"
**Output:** "bb"

**Constraints:**

- `1 <= s.length <= 1000`
- `s` consist of only digits and English letters.

## code
```python
class Solution:

    def longestPalindrome(self, s: str) -> str:

        n = len(s)

        def getlen(l,r):

            while l >= 0 and r < n and s[l]==s[r]:

                l-=1

                r+=1

            return r-l-1

  

        start = 0

        length = 0

  

        for i in range(n):

            cur = max(getlen(i,i),getlen(i,i+1))

            if cur <= length: continue

            length = cur

            start = i -(cur-1)//2

        return s[start:start+length]
```


**1. 題目資訊**

- **題目：** Longest Palindromic Substring
    
- **語言：** Python 3
    
- **輸入：** 字串 `s`，長度介於 `1～1000`，只包含英文字母與數字。
    
- **輸出：** 最長的回文子字串，而非長度；如果有多個答案，回傳其中一個即可。
    
- **子字串必須連續**，不能跳過中間字元。
    
- **回文：** 正向與反向讀取都相同，例如 `"aba"`、`"abba"`。
    

**2. 核心概念與解題流程**

本次使用的是**中心擴展法**。

如果某個片段已經是回文，且它外側新增的左右兩個字元相同，擴展後仍然是回文。例如：

```text
"b" → "aba" → "xabax"
```

回文中心有兩種形式，必須都檢查：

|回文類型|中心形式|初始左右索引|範例|
|---|---|---|---|
|奇數長度|一個字元|`i, i`|`"aba"`|
|偶數長度|相鄰兩個字元之間|`i, i + 1`|`"abba"`|

主要流程：

1. 依序走訪每個索引 `i`。
    
2. 分別嘗試奇數與偶數中心，向左右擴展。
    
3. 取這兩種情況中較長的回文長度。
    
4. 如果比目前紀錄更長，更新長度與起點。
    
5. 最後透過切片回傳答案。
    

方法能涵蓋所有答案，是因為**每個回文都有一個字元中心，或一個位於相鄰字元之間的中心**。

**3. 資料結構與變數角色**

題目指定的資料結構是字串 `str`。本解法以整數記錄索引與長度，不需要額外建立串列或字典。

|變數／函式|角色|
|---|---|
|`s`|原始字串|
|`n`|字串長度|
|`i`|本輪嘗試的中心索引；偶數情況中是中心左側的索引|
|`l`、`r`|擴展時，目前準備比對的左右索引|
|`getlen(l, r)`|從指定中心擴展，回傳最長回文長度|
|`cur`|本輪兩種中心所得到的較長長度|
|`length`|到目前為止找到的最長回文長度|
|`start`|目前最長回文的起始索引|

字串的存取方式：

```python
s[i]                  # 讀取一個字元
s[start:start+length] # 取得答案片段
```

Python 切片**包含起點、不包含終點**，因此長度為 `length` 的片段，終點參數是 `start + length`。

**4. 重要判斷、迴圈與公式**

**① 擴展迴圈的三個條件**

```python
while l >= 0 and r < n and s[l] == s[r]:
    l -= 1
    r += 1
```

|條件|原因|
|---|---|
|`l >= 0`|避免左側超出字串開頭|
|`r < n`|避免右側超出字串結尾|
|`s[l] == s[r]`|新加入的兩個字元必須相同，才能維持回文|

Python 的 `and` 會由左往右判斷，遇到 `False` 就停止，稱為**短路求值**。因此要先檢查邊界，再存取字元。

另外，`s[-1]` 會讀取最後一個字元；負索引雖然合法，卻不符合這裡向左擴展的目的。

**② 為什麼外層用 `for`，內層用 `while`？**

- 外層 `for`：需要依序走訪已知的索引範圍 `0～n-1`。
    
- 內層 `while`：擴展次數不固定，取決於邊界與字元是否相同。
    

迴圈的選擇依據是**走訪方式與停止條件**，不是字串題一定要用哪一種迴圈。

**③ 為什麼回傳 `r - l - 1`？**

每次成功比對後，左右索引都會再往外移一步。停止時，最後成功的回文範圍是：

```python
左端 = l + 1
右端 = r - 1
```

因此：

```python
長度 = 右端 - 左端 + 1
     = (r - 1) - (l + 1) + 1
     = r - l - 1
```

若偶數中心的兩個字元一開始就不同，迴圈不會執行，此公式會得到 `0`，表示該中心沒有非空回文。

**④ `max` 計算的目的**

```python
cur = max(getlen(i, i), getlen(i, i + 1))
```

- `getlen(i, i)`：尋找以單一字元為中心的最長回文。
    
- `getlen(i, i + 1)`：尋找以相鄰字元之間為中心的最長回文。
    
- `max(...)`：取本輪兩種情況的較長長度。
    

這裡處理的是**回文片段長度的奇偶**，與整個 `s` 的長度奇偶無關。

**⑤ 什麼時候更新答案？**

```python
if cur <= length:
    continue
```

`continue` 會跳過本輪剩餘內容，進入下一輪。

只有 `cur > length` 才更新紀錄；長度相同時保留原答案，符合題目要求。

**⑥ 起點公式如何兼顧奇偶？**

```python
start = i - (cur - 1) // 2
```

`//` 是向下取整除法，這裡用來算出要從 `i` 往左移動幾格。

|情況|`cur`|`(cur - 1) // 2`|起點|
|---|--:|--:|---|
|奇數回文 `"abcba"`|5|2|`i - 2`|
|偶數回文 `"abba"`|4|1|`i - 1`|

偶數情況中，`i` 已經在中心兩個字元的左側，所以長度為 `4` 時，只需再往左移一格。

本次以說明與手算理解程式，**未實際執行測試，也未取得 LeetCode 提交結果**。

已討論的例子：

|字串與中心|推導結果|觀察重點|

|`"xabax"`，`i = 2`|奇數中心可擴展至整個字串，長度 `5`|逐層向外比對|

可自行驗證的邊界案例：

|輸入|預期答案|檢查目的|
|---|---|---|
|`"a"`|`"a"`|單一字元|
|`"ac"`|`"a"` 或 `"c"`|沒有長度超過 `1` 的回文|
|`"abba"`|`"abba"`|偶數回文|
|`"aaaa"`|`"aaaa"`|大量重複字元|
|`"babad"`|`"bab"` 或 `"aba"`|多個等長答案|

**時間複雜度：最壞為 `O(n²)`。**

- 外層有 `n` 個索引。
    
- 每個索引嘗試兩種中心，屬於固定次數。
    
- 每個中心最壞需要擴展 `O(n)` 次，例如字元全部相同時。
    
- 合計最壞為 `O(n²)`。
    

**額外空間：不含回傳字串為 `O(1)`。**

- 只使用固定數量的索引與長度變數。
    
- 最後切片產生長度為 `k` 的結果字串，需要 `O(k)` 空間；若包含輸出，最壞為 `O(n)`。
