Windows 11 是微軟最新版本的作業系統，雖然其中有許多功能和設定依然與 Windows 10 相同，但還是增加了些新東西，其中包含一些獨特的鍵盤快捷鍵與組合鍵，讓你在使用電腦時可以更快地執行指定任務，並提升整體工作效率。這次，我們幫你把 73 個最重要的快捷鍵整理起來，你一定要好好了解一下。  

在這篇文章中，筆者將介紹 Windows 11 最重要的鍵盤快捷鍵，其中許多是從 Windows 10和微軟作業系統早期的版本代代相傳延續下來，這其中包括基礎知識，例如複製突出顯示的專案和取消以前的操作，以及鮮為人知的快捷方式，例如將活動視窗對齊定位等。

### Windows 11 快捷基礎知識 – 你最常用的部分

1. Ctrl + A：選擇視窗中的所有內容（全選的概念）。
2. Ctrl + C 或 Ctrl + Insert：複製所選擇的內容（文字、影像等）。
3. Ctrl + V 或 Shift + Insert：黏貼所選擇的內容
4. Ctrl + X：剪下所選的內容。
5. Ctrl + Z：恢復前一個操作。
6. Ctrl + Y：重做操作。
7. Ctrl + N：當檔案總管是目前正在使用的視窗時，開啟一個與目前視窗路徑相同的新檔案總管視窗。
8. Win + F1：在預設瀏覽器中打開「how to get help in windows 11」（如何獲得 Window 11 幫助）的 Bing 搜尋結果頁。
9. Alt + F4：關閉目前的應用程式或視窗。
10. Alt + Tab：在已經開啟的應用或視窗間切換。
11. Shift + Delete：永久刪除所選項目。（也就是跳過丟到資源回收桶這一步，直接永久刪除）

### 開始功能表和工作列

1. Win 鍵或 Ctrl + Esc：打開開始功能表。
2. Win + X：打開文字型的隱藏開始功能表。
3. Win + T：在工作列的應用之間循環切換（包含釘選應用）。
4. Win + 數字鍵：開啟釘選在工作列上的應用程式。舉例來說，如果你把 Edge 瀏覽器固定在工作列第一個位置，只要按「Win + 1」即可打開應用；如果應用已經開啟，則會打開一個新視窗。
5. Win + Alt + 數字鍵：打開釘選在工作列上指定位置應用的右鍵選單。（指定位置定義同上一條）
6. Win + D：顯示或隱藏桌面。（Win +, 則為快閃顯示桌面）

### 截圖 – 最常用的三種

1. PrtScn：擷取整個螢幕顯示畫面並保存到剪貼簿裡面。
2. Win + PrtScn：擷取整個螢幕顯示畫面並保存到電腦上的資料夾中。
3. Win + Shift + S：呼叫剪取工具快速功能表，可框選想要擷取的部分。

### 桌面 – Windows、Snap 助手和虛擬桌面的控制

1. Win + M：將所有打開的視窗最小化。
2. Win + Shift + M：還原最小化的視窗。
3. Win + Home：最小化除所選視窗或目前活動視窗之外的所有視窗。
4. Win + ↑：最大化所選取的視窗。
5. Win + Shift + ↑ / ↓：寬度不變的狀態下拉長 / 縮短所選視窗的長度
6. Win + ←：將所選取的視窗放置在螢幕的左半部。
7. Win + →：將所選取的視窗放置在螢幕的右半部。
8. Win + Alt + ↑：將所選取的視窗放置在螢幕的上半部。
9. Win + Alt + ↓：將所選取的視窗放置在螢幕的下半部。
10. Win + Tab：開啟虛擬桌面檢視模式。
11. Win + Ctrl + D：增加新的虛擬桌面。
12. Win + Ctrl + →：向右移動到下一個虛擬桌面。
13. Win + Ctrl + ←：向左移動到上一個虛擬桌面。
14. Win + Ctrl + F4：關閉目前的虛擬桌面。

### Win 鍵執行任務

1. Win + A：打開快速設定小面板。
2. Win + S / Q：開啟「搜尋」
3. Win + C：開啟聊天（Microsoft Teams）。
4. Win + E：開啟檔案總管。
5. Win + F：打開 Windows 問題回饋中樞。
6. Win + Ctrl + F：在網路上搜尋電腦。
7. Win + G：打開 Xbox Game Bar。
8. Win + H：打開 Windows 語音輸入功能。
9. Win + I：打開設定應用。
10. Win + K：打開投射面板。
11. Win + L：鎖定電腦。
12. Win + O：鎖定裝置方向。
13. Win + P：選擇簡報顯示模式。
14. Win + R：打開執行視窗。
15. Win + U：開啟協助工具設定。
16. Win + W：呼叫出小工具托盤。
17. Win + + / -：放大或縮小螢幕顯示。
18. Win + Esc：關閉放大鏡。

### Function 鍵

1. F2：重新命名所選檔案。
2. F3：在檔案總管中快速搜尋檔案。
3. F4：在檔案總管中顯示位址列清單。
4. F5：更新活動視窗。
5. F6：在視窗或桌面中的元素（分頁、按鈕、搜尋欄位等）之間循環切換。
6. Alt + F8：在登入畫面上顯示你的密碼。
7. F10：啟動使用中應用程式的功能表列。

### 命令提示字元快捷鍵

1. Ctrl + C 或 Ctrl + Insert：將所選文字複製到剪貼板。
2. Ctrl + V 或 Shift + Insert：將複製的文字黏貼到命令提示字元中。
3. Ctrl + A： 選擇當前行上的所有文字。（如果當前行沒有文字，則將選擇命令提示字元下的所有文字）
4. Ctrl + ↑ / ↓：向上或向下移動螢幕一行。
5. Ctrl + F： 透過查找視窗搜尋命令提示字元。
6. Ctrl + M： 進入標記模式（允許你使用滑鼠選擇文字），啟用標記模式後可以使用箭頭鍵移動游標。
7. Shift + ↑ / ↓：向上或向下移動游標一行並選擇文字。
8. Shift + ← / →：將游標向左或向右移動一個字元並選擇文字。
9. Ctrl + Shift + ← / →：將游標向左或向右移動一個單詞並選擇文字。
10. Shift + PgUp / PgDn：將游標向上或向下移動一個螢幕捲動並選擇文字。
11. Shift + Home / End：將游標移動到當前行的開頭或結尾，然後選擇文字。
12. Ctrl + Shift + Home / End： 將游標移動到螢幕緩衝區的開頭或結尾，然後選擇文字以及命令提示字元輸出的開頭或結尾。
