HTML（HyperText Markup Language，超文字標記語言）是用來描述網頁內容與結構的語言。

例如：

```html
<!DOCTYPE html>
<html lang="zh-TW">
<head>
  <meta charset="UTF-8">
  <title>我的網頁</title>
</head>
<body>
  <h1>歡迎來到我的網站</h1>
  <p>這是一段文字。</p>
  <button>點擊我</button>
</body>
</html>
```

三種網頁核心技術的分工：

|技術|功能|類比|
|---|---|---|
|HTML|定義內容與結構|房屋骨架|
|CSS|控制顏色、字體與排版|裝潢|
|JavaScript|實現點擊、計算等互動|水電與機械設備|

HTML 使用「標籤」描述內容：

```html
<h1>大標題</h1>
<p>段落文字</p>
<a href="https://example.com">前往網站</a>
<img src="image.png" alt="圖片說明">
```

其中 `href` 和 `src` 裡填寫的通常就是 URL。HTML 本身不是程式語言，因為它主要負責標記內容，而不負責運算或流程控制。
